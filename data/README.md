# data/

Local working area only. **Contents are git-ignored** (only this README and `.gitkeep` files are tracked).

| Folder    | Purpose                                                          |
|-----------|------------------------------------------------------------------|
| `raw/`    | Raw payloads downloaded during local connector development.      |
| `sample/` | Small extracts used for unit tests and offline development.      |

Production data lives in Delta tables on Databricks (Unity Catalog), not here.
Respect each source's licence before storing or redistributing any extract.
